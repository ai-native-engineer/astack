# VOD 강의 대본 생성 (녹화용 음성 원고)

> 완성된 VOD 클립 자료(노션 페이지/로컬 .md)에서 **강사가 녹화 때 읽을 구어체 음성 대본**을 뽑는다.
> 자료 본문 형식 자체는 [`vod-clip-template.md`](vod-clip-template.md)가 정본 - 이 파일은 그 자료를 말로 푸는 단계다. 둘을 섞지 않는다.

## 입력 -> 출력

- **입력**: 완성된 클립의 노션 page-id 또는 로컬 클립 `.md`. 자료의 **섹션 순서를 그대로** 따라간다(재배열 금지).
- **출력**: 인트로 -> 본문(섹션별) -> 아웃트로 구조의 음성 원고. 화면에 보이는 자료(표/이미지/코드)를 말로 안내하며 진행.

## 변환 규칙 (자료 -> 말)

- **학습 목표** 블록은 "이번 클립이 끝나면 ~를 할 수 있게 됩니다"로 풀어 인트로에 녹인다.
- **표/이미지**는 다시 읽어주지 말고 "화면의 ~를 보시면"으로 가리키고 핵심 1~2개만 짚는다.
- **코드/명령**(실습형)은 "이 명령을 따라 쳐 보겠습니다"로 안내, 한 줄씩 무엇을 하는지 말한다.
- 섹션 끝마다 핵심을 "이것만 기억하시면 됩니다" 한 줄로 압축.
- 곁가지(비용/요건)는 짧게 지나가고 핵심 개념에 시간을 둔다(우선순위 역전 금지).
- 클립 간 연결은 한 줄로("앞 클립에서 봤듯이", "다음 파트에서 다룹니다").

## 인트로/아웃트로 (기본값)

```
[인트로]
안녕하세요. 이번 클립에서는 <본문 범위를 풀어서> 같이 알아보겠습니다.
[필요 시: 이번 클립이 끝나면 여러분은 <학습 목표 N개>를 할 수 있게 됩니다.]

[아웃트로]
[필요 시: 정리하면, <이 클립의 결론 한 줄>입니다.]
이번 영상은 여기서 마무리하고 다음 영상에서 뵙겠습니다. 감사합니다.
```

- 인트로는 **페이지 제목을 그대로 읽지 않는다** - 본문이 다루는 범위(개념+곁가지)를 풀어서 예고한다. 제목만 읽으면 범위가 좁게 들린다.
- 결론 멘트(예: "이 강의는 VS Code로 진행합니다")가 본문 마지막에도 있으면 **아웃트로로 올려 중복을 없앤다**.
- 프로젝트에 고정 오프닝/클로징 문구가 있으면 프로젝트 규약을 우선한다.

## 언어/표기

- 준비된 친근, 정중 구어체("~합니다/~해요/~보겠습니다"). 채팅 슬랭도 격식체도 아니게.
- 한 문장 = 한 정보, 평서 단문. 추상 얼버무림 금지.
- 표기 금지 기호(화살표, em dash, 가운뎃점, 동그라미 숫자)와 클리셰 라벨은 [`anti-patterns.md`](anti-patterns.md)가 정본 - 대본 텍스트에도 그대로 적용한다.

## 반영 전 자기점검

- [ ] 섹션 순서가 자료와 1:1인가
- [ ] 학습 목표가 인트로에서 회수되나
- [ ] 화면에 보이는 표/이미지를 말로 다시 읽기만 하지 않았나(가리키고 핵심만)
- [ ] 인트로가 제목 복창이 아니라 본문 범위 예고인가, 결론 중복이 아웃트로로 정리됐나
- [ ] 금지 기호/클리셰 0인가
