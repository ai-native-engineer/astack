# Notion 회차 페이지 - child_page 분리형 변형 (<org>ax)

authoring.md 3-1절 단일 골격의 **변형**: 자료가 많아 한 페이지가 길어지는 회차에서 섹션을 child_page로 쪼개는 구조. **블록 문법, 골격은 [`template.md`](template.md)를 그대로 쓰고, 본문 토글 섹션을 child_page로 분리**하는 점만 다르다. (B2B/B2C 구분이 아니라 분량 기준 선택. 고객사 B 2회차에서 검증.)

---

## 1. 페이지 골격 (블록 순서)

```
1. callout (목표)            - template.md의 목표 callout과 동일 (아이콘은 💡, authoring 3-3절 팔레트)
2. table (시간표)            - 라이브 회차만, 2컬럼(시간 | 내용)
3. child_page (n개)          - 강의 섹션별 자료 페이지
4. child_page "마무리와 과제"  - Q&A, 과제 흡수 (마지막)
```

**핵심 원칙** (단일 골격과 다른 분리형 고유):

- "목표", "시간표", "자료" 같은 헤더 텍스트를 쓰지 않는다 - 블록 자체가 자명.
- 목표 callout은 bullet 5개 이내. 학습자 시점 동사로 끝내고("~만들어보기", "~체감하기"), 추상 표현은 금지(측정 불가한 "이해도 향상" 금지). 마지막 1개는 "본업 직결" 같은 실무 후속 액션과 연결.
- 자료는 단일 페이지에 욱여넣지 말고 **강의 섹션 수만큼 child_page로 분리** - 강사, 수강생 모두 섹션별 점프가 편하다.
- Q&A/과제는 **마지막 child_page "마무리와 과제"로 흡수**(빈 heading 안 둠). 강의 중 즉시 작성.

블록 본문 문법(callout/table/toggle 등)은 template.md가 정본. 신규 child_page 생성, 블록 순서 검증, 자산 보존은 [`notion-sync.md`](notion-sync.md) 4-2절(전체교체 프리플라이트, `API-post-page`)를 따른다.

---

## 2. 사용 시점

- 새 회차 강의 페이지를 Notion에 만들 때, 자료가 많아 한 페이지가 길어질 때
- 회차 페이지 골격을 child_page로 표준화하고 싶을 때

---

## 3. child_page 제목 규칙 (분리형 고유)

- "1. 저번주 복습" 식 번호를 붙이지 않는다 - 페이지에 보이는 순서가 곧 번호.
- 강의 내용 그대로("데이터 시각화 대시보드 만들기"), 외부 노출돼도 부끄럽지 않게(단순 키워드 나열 금지).
- 강의 섹션 흐름 순서대로 생성한다(생성 순서 = 표시 순서, API는 블록 reorder 미지원).

---

## 4. 변형 가이드

### 4.1 시간 블록 수 vs child_page 섹션 수 (혼동 주의 - 둘은 다른 축)
- **시간 블록**: 라이브 회차 시간표의 행. 강의마다 다름(예: 3시간이면 50분 강의 + 쉬는 시간 블록 - template.md 타임라인 참조). 회차별 구체 시간표(시작 시각, 블록 수)는 프로젝트 AGENTS.md/context에 둔다.
- **child_page 섹션 수**: 자료 단위. 제한 없음 - 자료가 많으면 잘게 쪼갠다(고객사 B 5회차는 12개). "섹션 3개"는 시간 블록 이야기지 child_page 수가 아니다.

### 4.2 1회차 ("저번주 복습"이 없을 때)
"저번주 복습" child_page 대신 "오리엔테이션"/"강의 소개"로 대체. "이번주 AI 뉴스"는 1회차엔 생략 가능.

### 4.3 데모데이 회차
발표 + 시상 + 회고 구조로 시간표 자체가 달라진다 - 이 분리형 템플릿 적용 X.

---

## 5. 체크리스트 (분리형)

- [ ] 목표 callout이 페이지 최상단(아이콘은 💡)
- [ ] (라이브면) 시간표 2컬럼
- [ ] child_page 제목이 강의 흐름 순서로 정렬
- [ ] 마지막 child_page "마무리와 과제" 존재(Q&A, 과제 흡수)
- [ ] 헤더 텍스트("목표", "시간표", "자료") 없음

---

## 6. 안티패턴 (분리형)

- ❌ "1. 저번주 복습" 식 번호 매기기 - 페이지 순서로 충분
- ❌ heading "목표"/"시간표"/"자료" 헤더 - 블록 자체가 자명
- ❌ 한 child_page에 모든 강의 자료 욱여넣기 - 섹션별 분리
- ❌ 강의 도중 자료 페이지 새로 만들기 - 강의 전 child_page를 미리 다 만들고 비워두기
