# VOD 클립 골격 - 매뉴얼형 (큰 틀)

> 선형으로 보는 VOD 클립의 매뉴얼형 골격. 실시간 빌드얼롱 회차는 [`template.md`](template.md)를 쓴다.

## 두 변형 (같은 DNA)

- **개념형**: 코드 없이 `이미지 -> 표/한 줄`. 무엇/왜/어디에를 보여줌(예: 3-1 도구 소개).
- **실습형**: `이미지 -> 실제 명령 코드 -> 미션`. 따라 치게 함(예: MCP 설정).

## 큰 틀 골격 (그대로 복사)

```
# 학습 목표
- 최소완료: [클립 길이 안에 반드시 달성할 관찰 가능한 목표]
- 선택확장: [난이도와 산출물에 따라 추가할 목표, 없으면 삭제]

---

# 1. [단계 또는 개념 - 평문 십진, 토글 없음]
[앞 클립 연결 한 줄 + 한 줄 정의. 여기까지가 글의 전부]
## 1.1 [하위 단계]
![무엇을 보여주는지 한 줄 캡션](이미지)        <- 실제 화면 먼저
[표(레퍼런스/비교) 또는 코드(실제 명령/복붙)]    <- 본체는 표나 코드가 짊
[한 줄 마무리. 기본값/다음 행동]
[[bookmark: 공식 URL]]                          <- 섹션 하단 카드

# 2. ... # 3. ...   [필요한 만큼. 정수 연속]

## 미션
1. [자기 업무로 치환하는 행동. "내 반복 작업 하나를 ~"]

## 요약
1. **[핵심 라벨]**: [한 줄]   (3가지)
```

## 언어 규칙 (어떻게 말하나)

- 준비된 친근,정중 구어체("~합니다/~해요/~봅니다"). 슬랭도 격식체도 아니게.
- 한 문장 = 한 정보. 평서 단문. **3줄 넘는 단락 금지**(설명충 진입점).
- 정의는 한 줄 먼저, 구체는 이미지/표/코드가 짊. 화면으로 보이는 건 글로 다시 풀지 않는다.
- 추상 개념엔 **비유 한 개로 고정**(매뉴얼, 표지 라벨, 통로 vs 매뉴얼). 얼버무림 금지.
- 클립 간 연결을 한 줄로("앞 클립에서 봤듯이", "다음 클립에서").
- 용어 첫 등장 1줄 풀이, 영어 명령/식별자는 백틱.

## 교육 설계 규칙 (어떻게 가르치나)

- 학습 목표 수는 클립 길이, 난이도, 산출물 크기에 따라 정한다. 최소완료를 먼저 두고 선택확장은 분리한다.
- 단위 리듬 = **개념 한 줄 -> 실제 화면(이미지) -> 표/복붙 코드 -> 한 줄**(worked example).
- 한 섹션 한 개념. 표로 청킹, 십진 헤딩으로 구조 신호. **토글로 숨기지 않는다**(선형).
- 곁가지(비용/요건)보다 핵심 개념에 무게(우선순위 역전 금지).
- 미션은 **자기 업무로 치환**(자기 반복작업 1개 떠올리기). 요약은 핵심 3가지.

## 제거 (설명충 차단)

- 이모지 헤딩(🎯/✅/🔑), STEP 토글, ⭐ "꼭 기억할 N가지", 📎 부록(강사메모는 본문 밖).
- 인라인 `[출처:]` -> 섹션 하단 `[[bookmark: URL]]` 카드.
- 콜아웃은 안전/핵심에만(💡/🚨/⚠️ 최소). 글리프(화살표/em대시/가운뎃점/동그라미숫자)는 평문.
- 상세 금지 목록은 [`anti-patterns.md`](anti-patterns.md)가 정본.

## 반영 전 자기점검

- [ ] 최소완료와 선택확장이 구분되고 본문에서 회수되나
- [ ] 모든 단위가 이미지 먼저 -> 표/코드 -> 한 줄 리듬인가
- [ ] 이미지가 보여주는 걸 본문이 다시 풀지 않았나, 3줄 넘는 단락이 없나
- [ ] 토글/이모지헤딩/⭐/부록/인라인출처가 0인가
- [ ] 미션이 자기 업무 치환인가, 요약이 핵심 3가지인가

블록 문법/콜아웃은 [`authoring.md`](authoring.md) 3-3절, 이미지 출처/삽입은 [`image-generation-notion-assets.md`](image-generation-notion-assets.md), 노션 반영은 [`notion-sync.md`](notion-sync.md)가 정본.
