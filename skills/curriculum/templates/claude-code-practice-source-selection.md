# Claude Code 실습 원문 선택 템플릿

이 템플릿은 Claude Code 실습 자료를 만들기 전에 원문 후보를 고르는 용도다. 새 실습 단계를 먼저 짜지 말고, `ntn`으로 확인한 원문 후보를 채운 뒤 사용자 선택을 받는다.

## 사용 규칙

- 원문 확인은 `ntn pages get <page_id>`로 한다.
- workspace와 page-id는 프로젝트 `AGENTS.md`에서 가져온다.
- 단계명은 선택된 원문 블록의 표현을 그대로 쓴다.
- 준비물, 도착점, 체크리스트는 보조 요소다.
- 원문에 없는 6단계, 8단계 흐름을 새로 만들지 않는다.

## 적용 체크

- [ ] 선택된 page id를 `ntn pages get <page_id>`로 다시 확인했다.
- [ ] 원문 실습 헤딩만 먼저 추출했다.
- [ ] 새 자료에는 원문 실습 순서를 먼저 박았다.
- [ ] 설명/콜아웃/표는 원문보다 길어지지 않게 압축했다.
- [ ] 원문에 없는 실습 단계는 사용자 확인 없이는 추가하지 않았다.
