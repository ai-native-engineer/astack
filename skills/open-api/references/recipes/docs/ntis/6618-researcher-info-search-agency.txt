1. 서비스 활용 방법
1.1. 홈페이지 가입
해당 기관에서는 관리자가 NTIS홈페이지(www.ntis.go.kr)에 회원으로 가입하여 오픈API 활
용신청을 할 수 있다.
1.2 서비스 활용신청 및 인증키 발급
NTIS홈페이지에 로그인 후 데이터활용 – OpenAPI 메뉴에서 신청하고자 하는 API의 ‘활용
신청’버튼을 클릭해서 오픈API 활용신청을 할 수 있다. 신청 버튼을 클릭한 후 NTIS센터
에서 승인을 하고 인증키를 발급합니다.
바로가기 URL : http://www.ntis.go.kr/rndopen/api/mng/apiMain.do

1.3 연구자정보제공동의
NTIS홈페이지에서 연구자정보 제공에 동의한 연구자들의 정보를 제공합니다(2025.12.11.
이후). 사용자가 동의를 원하지 않을 경우에는 ‘비동의’에 체크하면 됩니다.
바로가기 방법: NTIS홈페이지 로그인 → 마이페이지(이름 밑에) 클릭 →
‘연구자정보제공동의’메뉴 클릭 →
내용을 읽어보고 동의나 비동의 클릭 후 맨 아래의‘확인’ 버튼 클릭
