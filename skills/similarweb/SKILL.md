# Similarweb

## Overview

SimilarWeb 크롬 확장이 쓰는 비공개 엔드포인트(`data.similarweb.com/api/v1/data`)를
호출해 도메인의 트래픽·순위·유입·AI 챗봇 유입·키워드를 API 키 없이 가져온다.
`scripts/similar.py` 단일 스크립트에 캐시·스로틀·백오프가 내장돼 있다.

## Quick Start

`requests`만 필요하며, uv가 스크립트의 inline metadata로 자동 설치한다. 이 스킬
디렉토리의 `scripts/similar.py`를 실행한다(다른 경로에서 호출할 땐 절대경로 사용):

```bash
uv run scripts/similar.py github.com                       # 단일 상세
uv run scripts/similar.py github.com stripe.com vercel.com # 비교 표
uv run scripts/similar.py openai.com --ai                  # AI 챗봇 유입(GEO)
uv run scripts/similar.py wikipedia.org --keywords         # 키워드 SEO 가치
uv run scripts/similar.py github.com --history             # 월별 방문 추이
uv run scripts/similar.py github.com --json                # 정규화 JSON
uv run scripts/similar.py github.com --csv out.csv         # CSV
uv run scripts/similar.py github.com --raw                 # 원본 응답
```

출력 모드(상호 배타): `--ai`, `--keywords`, `--history`, `--json`, `--raw`, `--csv [PATH]`.
종료 코드: `0` 전체 성공 / `1` 전체 실패 / `2` 부분 실패.
튜닝 플래그(`--compare`, `--no-cache`, `--ttl`, `--interval`, `--retries`, `--proxy`)는 기본값으로 충분하니 평소엔 손대지 않는다 — 전체 옵션은 `similar.py -h`.

## 무엇을 얻나

- **기본 상세**: 글로벌·국가·카테고리 순위, 월 추정 방문, 이탈률, 페이지/방문,
  체류시간, 유입 국가, 트래픽 소스(Direct/Search/Social/GenAi…), 사이트 설명
- **`--ai`** (GEO): AI 챗봇 유입 비율 + LLM별 점유율(ChatGPT/Gemini/Claude/Perplexity)
  + 유입 프롬프트. 어떤 AI가 어떤 질문 맥락에서 사이트를 추천하는지 파악
- **`--keywords`**: 상위 키워드의 검색량·CPC·추정가치

## Rate limit — 반드시 알 것

엔드포인트는 AWS CloudFront + WAF 뒤에 있고 2층으로 막는다:

1. **봇 시그니처**: `python-requests` UA는 즉시 403. 브라우저 UA는 통과(스크립트에 내장).
2. **IP 단위 rate limit**: 짧은 시간에 많이 호출하면 IP가 수 분간 403 차단
   (`Request blocked / Generated by cloudfront`). 시간이 지나면 자동 해제된다.

**IP 분산(Tor/무료 프록시)은 통하지 않는다** — CloudFront가 Tor 출구 노드·알려진
프록시/데이터센터 IP를 reputation으로 차단한다(실측: Tor 출구 8/8 전부 403). 따라서
해결책은 "한도에 도달하지 않기"이고, 이 스크립트의 **디스크 캐시
(`~/.cache/similarweb/`) + 호출 스로틀 + 지수 백오프**가 그 역할을 한다. 막히면 몇
분 기다리거나 `--interval` 을 늘린다. 대량 수집이 꼭 필요하면 유료 residential
proxy(`--proxy`)만이 현실적 우회다.

**호출 한 번이면 충분하다 — 검증 목적의 재호출 금지.** 스크립트 출력은 이미
캐시·백오프를 거친 신뢰 가능한 결과다. 한 번 받은 출력으로 결론을 내고(예: "최신
월이 4월이면 5월 데이터는 아직 없는 것"), 같은 결론을 재확인하려고 `--no-cache`나
`--raw`로 신선 호출을 덧붙이지 않는다 — IP 차단 위험만 키운다. 진짜로 새 지표가
필요할 때만 추가 호출하고, 애매하면 호출하지 말고 먼저 사용자에게 묻는다.

## 라이브러리로

```python
import similar
s = similar.get("github.com")           # 정규화된 SiteData (캐시·백오프 적용)
print(s.global_rank, s.monthly_visits, s.ai_chatbots, s.keywords)
raw = similar.similarGet("github.com")  # 원본 호환: 원본 JSON dict
```

## 주의

- 서브도메인 요청은 메인 도메인 통계를 반환한다.
- `IsSmall`로 표시된 소규모 사이트는 추정치 신뢰도가 낮다(순위·소스가 비거나 0).
- 합법성: 엔드포인트는 숨겨졌을 뿐 금지된 게 아니며, 같은 데이터가 SimilarWeb
  웹사이트에 무료로 공개돼 있다.
