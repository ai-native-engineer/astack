# Discord Channel Overlay

Apply this after the common communication contract when the selected channel is Discord.

## Shape

- Put the purpose or requested action in the first line.
- Keep routine replies compact; use bullets for multiple actions or decisions.
- Use a thread when detailed context would interrupt the parent channel.
- Preserve code, links, and identifiers in Discord Markdown without adding decorative formatting.

## Mentions and Privacy

- Mention only the users or roles that need to act or know.
- Use `@everyone` or `@here` only when the user explicitly approves the audience and urgency.
- Keep reusable team context in an appropriate server channel; use DM for private feedback or sensitive details.

## Sending

- Confirm the server/channel and final body before sending.
- Keep mentions disabled unless the user explicitly approved them.
- Do not add an assistant signature.
