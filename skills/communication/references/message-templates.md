# Message Templates

Use these templates when an outbound message needs to be reusable, compact, and readable by a human who was not in the previous context.

## 목차

- Request / 3W1H
- Compact Handoff
- Status / Blocker
- Proposal / Buy-In
- Unknown / Follow-Up
- Attachment Context
- Correction
- Edit Checklist

## Request / 3W1H

```text
[무엇] 확인해주세요.

왜: [이 요청이 필요한 이유]
요청: [상대가 해야 할 일]
방식: [원하는 형태, 기준, 샘플, 파일]
기한: [언제까지]
판단 기준: [결정에 필요한 숫자/사례/조건]

확인 필요: [아직 모르는 점, 있으면]
```

## Compact Handoff

Use when the recipient needs field-ready context, not a full report.

```text
[상황/목적] 전에 이것만 먼저 봐주세요.

전제
- [이전 상태]
- [이번 상태]
- 그래서 [필요한 운영 기준]

핵심 판단
- [결론]
- 근거: [숫자/사례/관찰]

체크할 포인트
1. [구간/주제]
- 변수: [현장에서 생길 수 있는 일]
- 대응: [어떻게 처리할지]

2. [구간/주제]
- 변수: [현장에서 생길 수 있는 일]
- 대응: [어떻게 처리할지]

막히면
- [조건]이면 [fallback]으로 처리해주세요.

정리하면 [가장 중요한 실행 흐름]입니다.
```

## Status / Blocker

```text
결론
- [현재 판단/상태]

현재 상태
- [완료된 것]
- [진행 중인 것]

막힌 점
- [이슈]
- 영향: [무엇이 늦어지거나 달라지는지]

다음 액션
- [내가 할 일] / [언제까지]

필요한 결정
- [상대가 결정해야 할 것]
```

## Proposal / Buy-In

```text
결론은 [제안/판단]입니다.

상대 pain
- [상대가 실제로 겪는 문제]
- [상대가 쓰는 표현/요구]

핵심 판단
- Win theme: [pain -> 우리 강점 -> 기대 결과 한 문장]
- 근거: [숫자/사례/파일/관찰]

대안/경쟁 구도
- [대안/경쟁사]의 강점: [X]
- 이번 판단 기준에서는 [Y]가 더 중요합니다.

요청
- [상대가 결정/확인/수정할 것]
- 기한: [언제까지]
```

Use `OREO` for a sharper version:

```text
결론: [주장]
이유: [왜]
사례: [숫자/사례]
정리: [그래서 필요한 액션]
```

## Unknown / Follow-Up

```text
지금 정확히 확인되지 않은 부분은 [X]입니다.
[방법]으로 확인해서 [시간]까지 다시 공유하겠습니다.
현재는 [임시 기준/대안]으로 진행하면 됩니다.
```

## Attachment Context

```text
첨부한 [파일명]은 [어떤 기준의 자료]입니다.
[이번에 달라진 점] 때문에 [주의할 점]을 먼저 봐주세요.
```

## Correction

```text
정정합니다.
[이전 내용]이 아니라 [정정 내용]입니다.

영향
- [바뀌는 판단/액션]

다음 액션
- [누가 무엇을 하면 되는지]
```

## Edit Checklist

- Is the reader, purpose, action, and deadline clear?
- For requests, are why, what, how, and when visible?
- Are facts, requests, opinions, and feelings separated?
- Are jargon and vague intensifiers removed or explained?
- If something is unknown, is the follow-up method and time stated?
- Are only action-changing variables included?
- Does the selected channel overlay change the structure?
- Would a busy recipient understand the request in 5 seconds?
