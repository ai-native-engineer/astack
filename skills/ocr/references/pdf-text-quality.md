# PDF 텍스트 레이어 품질

## 생성 기본값과 예외

- 가로쓰기 PDF는 SKILL.md의 기본 명령을 사용한다. Apple Vision의 언어 보정은 활성 상태로 둔다.
- 세로쓰기 문서는 같은 대표 페이지를 `accurate + sandwich`와 `livetext + sandwich`로 처리해 비교한다. 원문 방향, 문자 간 공백, 선택 위치를 확인한 뒤 해당 문서에만 모드를 바꾼다. `accurate`가 모든 배치를 처리한다고 가정하지 않는다.
- 원본 이미지 품질을 보존하는 기본값은 일반 PDF 출력과 최적화 비활성화다. PDF/A, 회전 보정, 기울기 보정 등은 사용자가 요구하거나 문서에 필요한 경우에만 선택하고 외형을 다시 검증한다.
- 큰 작업은 본문과 코드/표 등 배치가 다른 대표 페이지를 먼저 처리한다. 운영 PDF 전체를 실험 대상으로 덮어쓰지 않는다.

## 생성 결과 검증

1. `scripts/inspect-pdf-text.swift`를 `swift`로 실행한다. 출력 PDF, `--source` 원본, 검사할 `--pages`와 원문에서 고른 `--expect` 문구를 전달한다. 스크립트는 PDF를 변경하지 않는다.
2. 페이지 수, 크기, 회전이 원본과 같은지 확인한다. 스크립트는 전체 페이지의 텍스트 유무도 보고하지만 빈 표지나 삽화 페이지를 자동 오류로 취급하지 않는다.
3. PDFKit 추출 결과와 `pdftotext` 결과를 대조한다. 한글/영문 단어 사이 공백을 유지하고, 글자마다 공백이 들어가지 않는지 확인한다. 공백을 제거한 비교만으로 이 검사를 통과시키지 않는다.
4. 원문에서 고른 문구가 공백을 포함한 상태로 검색되는지 확인한다. `--expect`는 원시 추출 문자열에서 정확히 찾으므로, 실패하면 해당 페이지를 원문과 대조한다.
5. 코드, 표, 다단, 각주가 있으면 읽는 순서도 확인한다. 대표 페이지를 렌더링해 외형과 선택 위치를 확인한다. 검사 스크립트는 이미지 재압축이나 화면 픽셀 동일성까지 검증하지 않는다.
6. 표본 검사 범위와 예외 페이지를 보고한다. 한 문구의 성공을 전체 OCR 정확도로 표현하지 않는다.

Swift/PDFKit 또는 Poppler를 사용할 수 없으면 Mac의 PDF 뷰어에서 선택, 복사, 검색을 확인하고 자동 대조를 못 했다고 명시한다. 확인하지 않은 항목은 통과로 표시하지 않는다.

## 기존 레이어 수정과 교체

- 이미 검색 가능한 PDF의 일반 읽기와 단어 검색은 이 스킬을 실행하지 않고 기존 텍스트로 처리한다. OCR 문제 수정이 명시된 경우에만 이 절차를 사용한다.
- 먼저 원본과 별도 후보를 두고, PDFKit과 Poppler의 원시 추출 결과를 비교한다. 같은 PDF라도 추출기마다 단어와 줄을 다르게 묶을 수 있다.
- 공백만 고치는 경로는 글자와 좌표를 보존하는 검증된 도구가 있을 때만 선택한다. 그런 도구가 없으면 PDF 내부 문자열을 임의로 치환하지 않고, 대표 페이지를 `accurate + sandwich`로 재인식한 별도 사본을 비교한다. 새 인식 결과는 원문 이미지와 대조한다.
- 공백만 수정한 후보는 `--source` 원본과 `--preserve-text --pages all`로 검사한다. 두 추출기 모두에서 공백 외 글자와 순서가 유지되는지 확인한다.
- `--redo-ocr`로 새로 인식한 후보에는 기존 인식 오류가 바뀔 수 있으므로 `--preserve-text`를 합격 조건으로 사용하지 않는다. 원문 이미지, 정상 공백을 포함한 문구 검색, 읽는 순서로 검증한다.
- 기존 레이어를 새로 인식할 때는 기본 명령에 `--redo-ocr`를 추가하고 별도 출력으로 저장한다. `--skip-text`는 기존 레이어를 고치지 않으며, OCRmyPDF의 `--force-ocr`는 페이지를 재래스터화하므로 교체의 기본값으로 쓰지 않는다.
- 읽는 순서나 외형이 바뀐 페이지는 검증된 페이지와 분리하고 원래 페이지를 유지한다. 더 잘 읽힌다는 이유만으로 글자 누락이나 순서 변경을 승인하지 않는다.
- 원본 경로 교체가 요청된 경우, 원본 백업과 후보 검증을 끝낸 뒤 파일별로 반영한다. 페이지/메모 식별 관계를 유지하고 복원 경로를 보고한다.
