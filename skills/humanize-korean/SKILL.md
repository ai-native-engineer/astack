# Humanize Korean

한국어 텍스트의 AI식 표현과 번역투를 탐지하고 의미, 장르, 격식을 보존하며 윤문한다. 입력 길이나 변경률만으로 처리 가능 여부와 품질을 판단하지 않는다.

## 원칙

- 사실, 주장, 조건, 부정, 불확실성, 강조의 정도와 논리 관계를 보존한다. 내용을 추가하거나 요약하지 않는다.
- 고유명사, 수치, 날짜, 직접 인용, 법조문, 영어 약어는 원형을 보존한다. 오류가 의심되면 임의로 고치지 말고 별도로 알린다.
- 장르와 register를 유지한다. 격식 자체를 AI 티로 보지 않으며, 공적 문장을 임의로 구어체로 바꾸지 않는다.
- 패턴은 문맥 속에서 판단한다. 룰북에 나온 표현도 필요한 용법이면 남기고, 목록에 없더라도 문제가 분명하면 의미를 보존하는 범위에서 고칠 수 있다.
- 수정량은 문제의 범위에 맞춘다. 자연스러운 문장은 유지하고, 변경률을 목표나 중단 기준으로 삼지 않는다.
- 입력 전체를 검토한다. 긴 입력은 문단·절 단위로 나누되 누락, 중복, 문맥 단절을 확인한다. 일부만 처리했다면 전체 완료로 보고하지 않는다.

## 절차

1. **룰북 확인**: 이 스킬 디렉토리 기준 `references/quick-rules.md`에서 S1·S2 패턴과 자체검증 체크리스트를 읽는다. 세부 판단이 필요하면 taxonomy나 rewriting playbook을 참고한다.
2. **원문 확보**: 붙여넣은 텍스트 또는 지정한 `.txt`/`.md` 파일을 원문으로 삼는다. 한국어와 다른 언어가 섞였으면 비한국어 원문을 보존하며 한국어 부분을 다룬다. 한국어 윤문 대상이 없거나 번역이 필요한 요청이면 범위를 설명한다.
3. **문맥 파악**: 사용자 지정 장르·독자·격식을 우선하고 전체 문맥으로 보완한다. 첫 부분만 보고 나머지 문체를 단정하지 않는다.
4. **탐지**: A~J 분류를 참고해 문제 구간, 관련 ID, 심각도, 수정 이유를 기록한다. 기계적 병렬, 관용적 군더더기, 번역투, 수동태 남용, 인용 과밀, 단조로운 리듬을 문맥과 함께 검토한다. 보호 대상은 구분한다.
5. **윤문**: 문단 단위로 처리한다. 기존 순서인 D, A, I, G, H, F, B, C·J, E는 검토 순서로 활용하되 문맥상 자연스러운 수정 순서를 택한다. 수정은 문장 간 연결과 전체 어조까지 확인한다.
6. **검증**: quick-rules 체크리스트와 원문 대조로 의미·사실·보호 대상, 장르·격식, 전체 입력의 반영 여부를 확인한다. 인용·수치·법적 표현·복잡한 조건과 큰 구조 변경은 더 면밀히 대조한다. 단순한 표현 수정은 해당 문장과 주변 문맥을 중심으로 확인한다. 문제가 있으면 해당 수정을 되돌리거나 고친 뒤 영향 범위를 다시 검증한다.
7. **저장**: 사용자 지정 위치가 있으면 그곳에, 없으면 하네스가 허용한 임시 위치의 실행별 작업 폴더에 `final.md`를 저장한다. 기존 파일과 다른 작업을 덮어쓰지 않는다. 임시 산출물이 저장소의 미추적 파일로 섞이지 않게 한다.
8. **검증 기록**: 본문 뒤 `<!-- HUMANIZE-SUMMARY ... -->` 주석에 처리 범위, 주요 탐지·수정, 체크리스트 결과, 남은 우려를 적는다. 글자수·변경률·카테고리별 건수는 정확히 계산할 수 있고 검토에 도움이 될 때만 기록하며 품질 기준으로 쓰지 않는다. 변경 예시는 대표적인 부분을 필요한 만큼 제시한다.
9. **응답**: 완료 범위, 검증 결과, 대표 변경, `final.md`의 절대 경로를 짧게 알린다. 기본은 파일 전달이며 사용자가 본문 출력을 요청하면 따른다. 미처리 구간이나 미해결 문제가 있으면 위치와 이유를 명시한다.

## 품질 판단

- **완료**: 입력 전체를 반영했고 의미·보호 대상·장르·격식 검증을 통과했으며 필요한 윤문을 마쳤다.
- **검토 필요**: 중의적 원문, 확인이 필요한 인용, 남겨야 할 수 있는 패턴 등 사용자 판단이 필요한 구간이 있다. 해당 구간과 이유를 제시한다.
- **부분 처리**: 처리하지 못한 범위가 있다. 완료한 범위와 남은 범위를 구분한다.

S1·S2는 검토 우선순위를 돕는 신호다. 잔존 건수나 변경률만으로 등급을 매기거나 자연스러운 표현을 강제로 바꾸지 않는다.

## 옵션

- `장르: 칼럼|리포트|블로그|공적` 또는 사용자 지정 장르
- `강도: 보수|기본|적극`
- `최소심각도: S1|S2|S3`

강도는 표현 수정의 적극성을 조절하며 의미·장르·격식 보존 원칙은 유지한다.
