# 장기 무음 편집

강의나 화면 녹화에서 학습 흐름을 해치지 않는 장기 무음만 제거할 때 읽는다.

## 판단 기준

- `silencedetect`, VAD, STT는 후보 탐색에만 사용한다.
- 녹화의 무음은 두 모집단이 섞여 있다 - 말 리듬(호흡, 문장 경계)과 대기(로딩, 생각, 조작). 대기만 자른다.
- 짧은 호흡, 발화 사이 쉼, 조용한 음절은 보존한다.
- 클릭, 설정, 실행, 로딩, 결과 확인처럼 화면에서 진행되는 내용은 무음이어도 보존한다.
- 길이만으로 삭제하지 않고 앞뒤 발화와 화면 맥락에서 불필요한 대기인지 확인한다.
- padding은 앞 문장의 종결 어미와 다음 발화의 첫 음절을 온전히 남긴다.

## 임계값은 측정해서 정한다

기준을 어림짐작하거나 다른 녹화의 값을 재사용하지 않는다. 화자마다 말 리듬이 달라 고정 기본값은 그 화자의 정상 쉼을 자른다.

```bash
python3 scripts/derive_silence_policy.py <workspace>/speech.json --output-md <workspace>/silence-policy.md
```

한 세션의 여러 클립은 같은 화자·같은 리듬이므로 `speech.json`을 모두 넘겨 하나의 정책을 뽑는다.

출력된 `min_duration`, `padding`, `min_cut_gain`을 `build_mixed_cut_plan.py`에 그대로 넘긴다. 다른 값을 쓰려면 분포표의 어느 근거로 벗어나는지 검토 기록에 남긴다.

`min_cut_gain`은 컷 하나가 최소한 벌어야 하는 시간이다. 접합부는 연속성을 깎으므로 그만큼 못 버는 구간은 계획에 넣지 않는다 - 자잘한 컷이 쌓이면 삭제량은 안 늘고 말 리듬만 끊긴다.

## 작업 흐름

1. `scripts/video_silence_cut.py`의 dry-run으로 후보 시작·종료·길이를 확인한다.
2. `scripts/derive_silence_policy.py`로 이 녹화의 임계값·padding·최소 이득을 뽑는다.
3. 그 값으로 만든 계획의 접합점 3~5곳을 실제로 재생해 문장 경계와 화면 진행을 확인한다.
4. 검토한 후보만 원본 좌표의 계획에 넣고 모든 예정 접합점을 다시 확인한다.
5. 렌더 뒤 전체 디코드와 실제 화면·오디오 접합점을 검사한다.

전체 옵션은 각 스크립트의 `--help`를 따른다. 삭제할 근거가 없으면 빈 `remove_intervals`의 보존 계획을 사용한다.

마커 편집도 필요하면 무음 전용 렌더를 중간 원본으로 쓰지 않는다. 마커 판단을 먼저 끝낸 뒤 `scripts/build_mixed_cut_plan.py`로 장기 무음 후보를 합치고, 생성된 draft를 다시 검토해 원본에서 한 번 렌더한다. VAD 발화 구간의 여집합은 삭제 계획으로 사용하지 않는다.

## 화면 보정

무음 컷이 화면 점프를 만들면 긴 무음 전체를 복원하지 않는다. 직접 확인한 순수 무음 interval만 `scripts/refine_visual_silence_plan.py`로 장면 변화 주변에서 나누고, 새 draft 계획의 발화 경계와 화면을 다시 검토한다.

보정 뒤 화면 접합부와 장기 무음을 모두 재검사한다. 화면을 살리면서 불필요한 정적 대기를 되살릴 수 있기 때문이다.

## 출력 품질

정확한 컷은 재인코딩될 수 있다. 원본은 수정하지 않고 영상 특성과 모든 오디오 트랙을 가능한 한 유지하며, 최종 보고에 재인코딩 여부와 구조·디코드 검증 결과를 남긴다.
